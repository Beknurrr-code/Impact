# IMPACT — кабинет эколога для заводов Казахстана

**Демо:** https://impact-kz.netlify.app · карта: https://impact-kz.netlify.app/app.html

IMPACT — B2B-платформа мониторинга выбросов для промышленных предприятий. MVP — программа поверх уже установленных датчиков (CSV/API), оборудование — через партнёров.

- **Откуда дует: вероятные источники** — при превышении ранжируем трубы из реестра в секторе ±22,5° против ветра, с весом по расстоянию и уверенностью в %.
- **Здоровье данных** — статусы Online/Offline/Flatline/Spike/Missing и полнота в %. Пропуски всегда помечаются; оценка по соседям только пунктиром на графике и не входит в цифры отчёта.
- **Режим НМУ** — официальные предупреждения Казгидромета + индикатор погодного риска (не официальный прогноз), чек-лист мер и журнал действий.
- **Отчёт** — цифры считает код, LLM пишет только резюме, эколог утверждает.

Экономика (гипотеза): доступный рынок 113 × 150 000 × 12 = 203,4 млн ₸/год, потолок 1,29 млрд; клиенты 3/8/15 → выручка 2,7/9,9/20,7 млн ₸; цена 150k, COGS 30k, маржа 120k, CAC 480k, LTV 1,44 млн, LTV/CAC 3,0, окупаемость 4 мес.

## Стек
- **Frontend:** HTML/CSS/JS, MapLibre GL (2D/3D), тайлы OpenFreeMap, дизайн в стиле iOS 26 Liquid Glass (`public/`)
- **Backend:** Netlify Functions на Node.js (`netlify/functions/`), доступны по `/api/*`
  - `/api/sensors`: датчики и PM2.5
  - `/api/epicentres`: откуда дует — направление, сектор ±22,5°, кандидаты-трубы и уверенность
  - `/api/anomalies`: аномалии
  - `/api/broken`: неисправные датчики
  - `/api/forecast`: прогноз НМУ (живая погода Open-Meteo)
  - `/api/explain`: ИИ-объяснение и отчёт
- Frontend забирает данные из backend через `fetch('/api/...')`.

## Бизнес-модель (гипотеза)
150 000 ₸/мес за предприятие (гипотеза). Рынок: потолок 1,29 млрд ₸ (718 предприятий, UNECE), доступный 203,4 млн ₸ (113 заводов). Маржа 120 000 ₸ (80%), CAC 480 000 ₸, LTV 1,44 млн ₸ (12 мес), LTV/CAC 3,0, окупаемость 4 мес. Клиенты 3/8/15, выручка 2,7/9,9/20,7 млн ₸ — всё гипотеза.

Новое в v6: ИИ-помощник (/api/assistant), Сравнение факт/ПДК/бенчмарк (/api/compare) с журналом мер, Прогноз 48 ч, Календарь отчётности (с поверкой датчиков), Журнал инцидентов, экспорт отчёта в PDF.

## Данные
- 113 заводов обязаны по закону ставить автоматическую систему мониторинга выбросов (Минэкологии РК): https://ortcom.kz/en/press-relizy/1790762235
- 11 из 70 городов — высокое загрязнение (Казгидромет, 2025)
- 718 предприятий I категории (UNECE): https://unece.org/sites/default/files/2024-12/6_Kazakhstan.pdf

## v4: SaaS-кабинет, несколько площадок, гауссова модель (демо)
- `/app.html` — кабинет: Обзор, Карта 3D, Датчики, Откуда дует, Режим НМУ, Отчёты, Настройки (hash-роутинг), светлая/тёмная тема.
- 7 площадок РК (координаты приблизительные, OSM): ТЭЦ №1 и ТЭЦ №2, Астана; ТЭЦ, Караганда; металлургический комбинат, Темиртау; ГРЭС, Экибастуз; алюминиевый завод, Павлодар; цинковый завод, Усть-Каменогорск (все — демо, обобщённые названия).
- Все `/api/*` принимают `?plant=id`; новые `/api/plants`, `/api/grid`.
- Модель: гауссов факел, классы устойчивости Паскуилла (ветер, облачность, день/ночь из Open-Meteo), подъём факела по Бриггсу; вклад трубы = C_i/ΣC_i, уверенность — по совпадению модели и измерения. Демо-модель, параметры выбросов условные.

## Как включить GitHub Pages
Settings → Pages → Build and deployment: **Deploy from branch** → ветка `main`, папка `/ (root)` → Save.
Сайт будет на https://beknurrr-code.github.io/Impact/ . Сервер не нужен: все расчёты в `js/api.js` (собран из `netlify/functions` командой
`npx esbuild src/api-entry.js --bundle --minify --format=iife --outfile=js/api.js`), реальные данные берутся из Open-Meteo прямо из браузера.
